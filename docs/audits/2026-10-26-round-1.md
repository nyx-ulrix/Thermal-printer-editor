# Audit round 1 (2026-10-26)

Three read-only auditors ran in parallel.

## Security (no critical or high)

| # | Sev | Where | Finding | Outcome |
|---|---|---|---|---|
| S1 | medium | server.mjs | Stateless 30-day `sid`; logout does not end the session | Fix: server-side sessions, 7 days sliding, logout deletes |
| S2 | medium | server.mjs | `AGENT_TOKEN` has no strength rule or rate limit | Fix: ≥32 chars, bad tokens count toward the limiter |
| S3 | medium | server.mjs | `ALLOW_OPEN_BOARD=1` accepted in production | Fix: refused with https origins or `NODE_ENV=production` |
| S4 | low | server.mjs | Non-Latin-1 return path → 500 after the code is spent | Fix: printable ASCII only |
| S5 | low | server.mjs | Cookie shadowing from sibling subdomains | Fix: `__Host-` cookies, any matching cookie may verify |
| S6 | low | server.mjs | `cf-connecting-ip` trusted from anyone | Accepted: origin is only reachable through the Cloudflare tunnel (known limit in HANDOVER) |
| S7 | low | server.mjs | Raw payloads kept in the event log forever | Fix: separate payload store, deleted when the job finishes |
| S8 | low | server.mjs | Auth-gated assets `public, immutable` | Fix: `private` |
| S9 | low | server.mjs | SSE starvation, no backpressure | Fix: 5 streams per user, slow clients dropped |
| S10 | low | server.mjs | No editor storage quota; case-insensitive key collisions | Fix: quota, binary collation / collision check |
| S11 | low | server.mjs | Attacker text in logs | Fix: JSON-encode |
| S12 | low | server.mjs | No HSTS | Fix |
| S13 | low | agent | Raw TSPL passed through unfiltered | Accepted: by design, only signed-in allow-listed users can print |
| S14 | low | agent unit | systemd hardening incomplete | Fixed |
| S15 | low | install.sh | Existing env file permissions not fixed | Fixed: root 600 on every install |

## Correctness and robustness

| # | Sev | Where | Finding | Outcome |
|---|---|---|---|---|
| C1 | high | server.mjs | Torn last log line blocks boot forever | Fix: skip torn final line, stream the file |
| C2 | high | agent | Agent restart before ack reprints | Fix: persisted state file, "printing" marker |
| C3 | medium | server.mjs | `print.sent` not persisted | Fix: persisted |
| C4 | high | server.mjs | Data API timeout can commit an event the server thinks failed | Fix: event ids, dedupe |
| C5 | high | server.mjs | Boot loads every payload; can exceed memory/timeout | Fix: payloads out of the log, boot retries |
| C6 | medium | server.mjs | Jobs never pruned; stale raw jobs print hours later | Fix: prune after 24 h, expire queued raw jobs after 1 h |
| C7 | medium | server.mjs, agent | Slow append stalls poll; duplicate `print.finished` | Fix: in-flight set, agent timeout 30 s |
| C8 | medium | bridge.ts | Lost print response → user prints twice | Fixed: client `jobId` idempotency + retries; timeout shown as queued, not error |
| C9 | medium | agent | Transient USB/CUPS error fails the job permanently | Fix: leave unacked, redelivered |
| C10 | low/med | server.mjs, bridge.ts | editor_kv duplicate-key race; optimistic cache not rolled back | Fixed in bridge; server retries PATCH |
| C11 | low | index.html | Card shows the wrong job when a task was printed twice | Fix: order by immutable `requested` |
| C12 | low | server.mjs | One malformed kv row breaks the editor boot | Fix: validate on load |
| C13 | low | server.mjs | SSE backpressure | Fix (with S9) |
