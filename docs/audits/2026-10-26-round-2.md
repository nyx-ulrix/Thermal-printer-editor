# Audit round 2 (2026-10-26)

Ran on the code after the round-1 fixes. No critical or high findings in any dimension.

## Security

| # | Sev | Finding | Outcome |
|---|---|---|---|
| M1 | medium | Cookieless `/auth/callback?state=x` counted as a failed sign-in; 20 from any web page locked the IP out, and the agent shared the counter (reproduced) | Fix: only token-exchange/claim failures count; separate agent limiter |
| L1 | low | Limiter map cleared at 10k entries, resetting lockouts | Fix: stop adding / evict instead |
| L2 | low | `GOOGLE_TOKEN_URL` test override honoured in production | Fix: refused with https origins or production |
| L3 | low | Parallel PUTs overshoot the 64 MB editor quota; no cap on queued raw jobs | Fix: reserve before write; cap raw jobs |
| L4 | low | File store uses default umask | Fix: 0700 dirs, 0600 files |
| L5 | low | Agent token inherited by CUPS helpers | Fixed: removed from the environment after config load |
| L6 | low | Agent state temp file follows symlinks | Fixed: `O_NOFOLLOW` |
